Como funciona?
O client pede uma informação pelo navegador, e vem uma requisição HTTP até o CentOS, que vai pedir ao NGINX, 
que vai voltar HTML,CSS,Javascript,.... até o client.

Tipos de Servidores:

Servidor - Proxy:
client <> Servidor - proxy(bloqueio) <> internet <> servidor web

Servidor - Firewall:
client <> Servidor - Firewall(defesa) <> internet <> servidor web

Servidor - Web Server:
client <> internet <> Web server

Servidor - Database:
client <> internet <> Application server/Web server <> Banco de Dados Server

Servidor - Database:
client <> intranet <> Application server/Web server <> Banco de Dados Server

Servidor - DNS - Domain name server(converte nome para IP)
Clientes <> DNS <> Servidor web
