Sobre HTML

O HTML é uma linguagem de marcação, ela não é necessáriamente uma linguagem de programação.

H1 ate H6

São tags de cabeçalho utilizadas para definir o peso do cabeçalho do HTML.

P

São tags de parágrafo utilizadas para definir o conteúdo textual do HTML.

A

São tags de link utilizadas para definir o conteúdo de navegação do HTML.

IMG

São tags de imagem utilizadas para definir o conteúdo visual do HTML.

UL e OL

São tags de lista utilizadas para definir o conteúdo de listas do HTML.

INPUT

São tags de entrada utilizadas para definir o conteúdo de campos de formulário do HTML.

LINK e 'A'

São tags de link utilizadas para definir o conteúdo de navegação do HTML.

'BR' e 'HR'

São tags de quebra de linha e linha horizontal utilizadas para definir o conteúdo de espaçamento do HTML.

CITAÇÂO

São tags utilizadas para definir o conteúdo de citações do HTML.
