# Estudos de HTML e Web

Repositório de anotações e exercícios práticos criados durante o estudo de fundamentos web: história da internet, clients/servers, linguagens de programação e HTML/CSS na prática.

## Estrutura

### `00 - Inicio/`
| Arquivo | Assunto |
|---|---|
| [`01 - Historia da web.md`](00%20-%20Inicio/01%20-%20Historia%20da%20web.md) | História dos computadores e origem da internet/web (Arpanet, TCP/IP, Tim Berners-Lee, W3C) |
| [`02 - O que sao clients.md`](00%20-%20Inicio/02%20-%20O%20que%20sao%20clients.md) | Conceito de client, responsividade e compatibilidade entre navegadores |
| [`03 - O que sao servers.md`](00%20-%20Inicio/03%20-%20O%20que%20sao%20servers.md) | Tipos de servidores (proxy, firewall, web, database, DNS) e hospedagem de sites |
| [`04 - Linguagens de programacao.md`](00%20-%20Inicio/04%20-%20Linguagens%20de%20programacao.md) | Linguagens client-side e server-side |
| [`01 - index.html`](00%20-%20Inicio/01%20-%20index.html) | Exemplos práticos de tags HTML (formatação de texto, ID x class, formulários, imagem, listas, links) |
| [`Estrutura_style.css`](00%20-%20Inicio/Estrutura_style.css) | Exemplos práticos de propriedades CSS aplicadas ao HTML acima |

### `01 - Conceitos Basicos/`
| Arquivo | Assunto |
|---|---|

## Como visualizar

Basta abrir os arquivos `.html` em um navegador para ver os exemplos renderizados. O `01 - index.html` usa o estilo do `Estrutura_style.css` (mesma pasta).
