# Estudos de HTML e Web

Repositório de anotações e exercícios práticos criados durante o estudo de fundamentos web: história da internet, clients/servers, linguagens de programação e HTML/CSS na prática.

## Conteúdo

| Arquivo | Assunto |
|---|---|
| [`01 - Historia da web.md`](01%20-%20Historia%20da%20web.md) | História dos computadores e origem da internet/web (Arpanet, TCP/IP, Tim Berners-Lee, W3C) |
| [`02 - O que sao clients.md`](02%20-%20O%20que%20sao%20clients.md) | Conceito de client, responsividade e compatibilidade entre navegadores |
| [`03 - O que sao servers.md`](03%20-%20O%20que%20sao%20servers.md) | Tipos de servidores (proxy, firewall, web, database, DNS) e hospedagem de sites |
| [`04 - Linguagens de programacao.md`](04%20-%20Linguagens%20de%20programacao.md) | Linguagens client-side e server-side |
| [`Estrutura_index.html`](Estrutura_index.html) | Exemplos práticos de tags HTML (formatação de texto, ID x class, formulários, imagem, listas, links) |
| [`Estrutura_style.css`](Estrutura_style.css) | Exemplos práticos de propriedades CSS aplicadas ao HTML acima |

## Como visualizar

Basta abrir o `Estrutura_index.html` em um navegador para ver os exemplos práticos renderizados com o estilo do `Estrutura_style.css`.
